# 三机协同吊运 —— 期望偏航跟随路径切线方向

> 三机协同吊运（Crazyflie 2.1 Brushless）仿真 · **版本 B**
> 基于 Lee 2014 (arXiv:1403.3684) / Lee 2018 (IEEE TCST) 的几何控制框架
> MATLAB R2021b · 纯 MATLAB 实现，无附加工具箱依赖

---

## 1. 这是什么

与 A 版相同的三阶段任务（起飞 → 绕两个八字环绕两个锥 → 降落），
但**期望偏航改为沿路径切线方向**（论文原式
`R0d = [x_dot/||x_dot||, e3×x_dot/||e3×x_dot||, e3]`）。
即"负载第一轴指向速度方向、偏航随路径转"。

**⚠ 重要局限（必读）**：参考端已正确指向切线，但**负载实际偏航跟不上**
（环绕段跟踪误差均值 85.8°）。原因是结构性的，不是参数问题 —— 详见 §5.3。

**与另外两个版本的关系**：见 [../README.md](../README.md)。

## 5. 关键机制（读这个才能改对参数）

### 5.1 参考端的切线取"理想八字的解析切向"，不是"实际速度方向"

**这是本次改动能成立的核心。** 直接用实际速度方向会踩两个坑：

1. **方向退化**：环绕段 `v = env'·p_hat + env·s·v_hat`，在两端 `env→0` 且 `env'→0`
   ⇒ `|v|→0` ⇒ `atan2` 的**方向无定义**。起飞/降落段同样有水平速度过零点。
2. **拼接不连续**：起飞段速度方向约 149°，与环绕段端点切向 0° 不一致。

改用**理想八字（不含包络）的解析切向**：

```text
u(tau) = aX·wX·cos(wX·tau)      v(tau) = (aY/2)·wY·sin(wY·tau)
psi    = atan2(v, u)
psi_dot = (u·v' − v·u')/(u²+v²) · s       ← 解析，d/dt = s·d/dtau
```

- 两分量**不会同时为零**（`wX = 2·wY`，联立要求 `k = 2m − 1/2`，无整数解）⇒ 全程良定义；
- `tau=0` 与 `tau=tEnd` 处 `v=0, u>0` ⇒ `psi = 0`，与起飞/降落段**天然连续**
  （实测 `psi(tEnd) = -1.3e-16 rad`）。

因 `b3d ≡ e3`，`R0d = Rz(psi)` 是**绕世界 z 的纯偏航** ⇒
`Omega0d = [0;0;psi_dot]`（解析），`Omega0dDot = [0;0;psi_ddot]`
（`psi_ddot` 只对**解析的** `psi_dot` 做**一次**中心差分 ——
旧实现是对 `R0d` 做**二阶**差分，噪声大一个量级）。

### 5.2 位置跟踪完全不受影响

参考端改动只走前馈，位置环增益未变 ⇒ 全部位置判据与安全裕度与 A 版一致（见 §4）。

### 5.3 ★ 为什么负载偏航跟不上（结构性，非参数问题）

偏航通道的反馈增益是 **0**（`kR0(3) = kOmega0(3) = 0`，`Md(3) ≡ 0`），
参考偏航只能通过极小的前馈项（`hat(ff)·J0·ff + J0·R0'R0d·Omega0dDot`，
量级约 1e-3 N·m）进入控制器，**几乎不影响动力学**。

**而把它打开（哪怕只给 0.0183 的纯阻尼）就发散 —— 且已在"转动阻尼已就位"的前提下重测：**

| `KR0(3)` | `KO0(3)` | `\|Omega0\|` 峰值 | 偏航误差均值 | 结果 |
|---|---|---|---|---|
| 0 | 0 | 4.03 | 85.8° | 稳定（基准） |
| 0 | 0.0183 | 1.6e11 | 84.9° | **发散** |
| 0 | 0.05 | 2.0e11 | 84.9° | **发散** |
| 0.02 | 0.0183 | 6.5e7 | 84.9° | **发散** |
| 0.1 | 0.0183 | 1.2e9 | 84.9° | **发散** |
| 0.3828 | 0.0183 | 3.1e12 | 84.9° | **发散** |

⇒ **§12.16 的转动阻尼只解决了"无阻尼振荡"，并没有解锁偏航反馈。**

**机理**：负载偏航力矩只能靠**把近乎竖直的绳索"扭出"水平分量**来交付。
需求 `Md(3)` 时，分配解 `mu_id` 必须给出水平分量
`|mu_h| ≈ |Md(3)|/(n·rho)`；本构型 `rho ≈ 0.1 m`（0.2 m 负载）
⇒ **力臂很小** ⇒ 需要**很大的水平张力** ⇒ `q_id` 被甩出大角度 ⇒ 与绳向环形成正反馈。

论文能控偏航，是因为它的负载是 1.0×0.8 m、绳长 1 m，**力臂大一个量级**。

**⇒ 结论**：在本构型下，要真正让负载偏航跟随切线，只能动**力臂**
（放大负载 / 把挂点铺到角上 / 加长绳索），而不是调增益。
其余机制（挂点 2:1:1、kR ×8、转动阻尼、blendTime、USE_QID_DOT）
与 A 版完全相同，见 `ENGINEERING_LOG.md` 或 A 版 README 的 §5。
